Maquette S12 — les blocs des machines modulaires

Maquette à valider : rien n'est encore branché. Elle ajoute une section « Ensemble modulaire » dans l'éditeur de bâtiments, sous « Interface », pour les 23 blocs des trois ensembles (ferme d'arbres, moteur diesel, turbine). Les valeurs viennent de data/modular.json (S11 et tes réponses MOD), chacune avec sa source. Rien n'est calculé ni placé ici : le calcul vient en S13, les plans de pose en S14.

1. Dans la liste des bâtiments : un repère

Le repère dit à quel ensemble le bloc appartient. La recherche « ferme », « moteur » ou « turbine » trouve tous les blocs de l'ensemble.

2. Un bloc assemblé par contact : Diesel Engine Crankshaft

Ensemble modulaire · Moteur diesel modulaire (Tier II) · par contact : les blocs se touchent, face contre face

Controller→Crankshaft × n→Generator

Sur les côtés des vilebrequins : Cylinder, Air Input, Exhaust, Fuel Input, Info Panel, Decoration, Crankshaft Sideways (2ᵉ ligne).

Les faces se lisent dans le sens de la chaîne : devant = vers le générateur, derrière = vers le contrôleur, côtés = les deux faces latérales.
